# AWS Architecture Icons

These SVG files come unmodified, with their original file names, from the official AWS Architecture
Icons package released on 2026-07-31 (`Architecture-Service-Icons_07312026` and
`Resource-Icons_07312026`), downloaded from https://aws.amazon.com/architecture/icons/.

AWS allows customers and partners to use these icons in architecture diagrams and related materials.
OpsWatch uses each icon only to represent the AWS service it names, without recolouring or distorting it.
Performance Insights has no icon in the package, so OpsWatch shows a generic icon for it instead.

Files:

- `Arch_AWS-CloudFormation_48.svg`: AWS CloudFormation
- `Arch_AWS-Identity-and-Access-Management_48.svg`: AWS Identity and Access Management
- `Arch_Amazon-Elastic-Container-Service_48.svg`: Amazon Elastic Container Service
- `Arch_Amazon-EC2_48.svg`: Amazon EC2
- `Arch_AWS-Application-Auto-Scaling_48.svg`: AWS Application Auto Scaling
- `Arch_Elastic-Load-Balancing_48.svg`: Elastic Load Balancing
- `Arch_Amazon-RDS_48.svg`: Amazon RDS
- `Arch_Amazon-Aurora_48.svg`: Amazon Aurora
- `Arch_Amazon-CloudWatch_48.svg`: Amazon CloudWatch
- `Res_Amazon-CloudWatch_Logs_48.svg`: Amazon CloudWatch Logs
- `Res_Amazon-CloudWatch_Alarm_48.svg`: Amazon CloudWatch alarm
